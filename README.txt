WELCOME TO MY PROJECT SPACE

Thanks for stopping by. This workspace brings together three small projects I’ve
been building while learning front-end development. Start at the home page to
get a quick introduction, then use the navigation or project cards to explore.

GETTING STARTED

The quickest way to explore is to open index.html in your browser. You can also
open the Task 4 folder in VS Code and use Live Server if you prefer running the
pages from a local server. No build step or package installation is required.

PROJECTS

1. Project hub — index.html
   The front page for this workspace. It links to all three projects and includes
   a responsive mobile menu, animated project cards, and page transitions.

2. Portfolio — naman_bansal_portfolio/
   A personal portfolio with an introduction, skills, selected projects, learning
   journey, and contact links. The Home link in the navigation returns here.

3. To-do list — todo-list/
   A small task manager for adding, completing, filtering, and removing tasks.
   Tasks are saved in your browser, so they remain available on the same browser
   and device. They are not synced between devices.

4. Product shop — product-listing/
   A responsive product catalog with category and price filters, search, and
   sorting by rating or price. Use the moon/sun button to switch between light
   and dark themes; your theme preference is saved in this browser. The bag
   counter is a front-end demo and is not connected to checkout.

HOW THE PROJECTS ARE ORGANIZED

- index.html, home.css, home.js: project hub and its navigation/animations
- naman_bansal_portfolio/: portfolio page, styles, and interactions
- todo-list/: to-do page, styles, and task interactions
- product-listing/: product catalog, styles, and filtering/sorting interactions

Each project is a standalone page with its own styles and JavaScript. Keep the
folders together so the links between pages continue to work.

A QUICK NOTE ABOUT WHAT’S CONNECTED

These are static front-end projects; there’s no server or backend behind them.
The contact area links to LinkedIn and GitHub rather than submitting a message.
The product filters, sort options, theme toggle, and demo bag work in the page,
but the bag does not place orders or process payments.
